# skill-of-the-day - персональный roadmap по живым вакансиям

Сервис, который подсказывает пользователю, какой навык изучать следующим, опираясь на актуальные вакансии hh.ru, а не на общий roadmap.

## Проблема

Начинающие разработчики тратят месяцы на навыки, которые дают минимальный прирост к числу доступных вакансий. Общие roadmaps не учитывают регион, уровень и текущий стек конкретного человека.

## Как работает

1. Пользователь выбирает направление, уровень, регион и отмечает свои текущие навыки.
2. Сервис подтягивает свежие вакансии с hh.ru через API и разбирает их требования: обязательные навыки, желательные и просто упомянутые технологии.
3. Система объединяет разные названия одного навыка, считает статистику по выбранной специализации, уровню и региону.
4. Пользователь получает персональный список недостающих навыков, отсортированный по тому, насколько каждый из них расширяет доступный ему рынок вакансий.
5. Для каждого навыка видно, на каких вакансиях основана рекомендация, примерное время на освоение и план на несколько шагов вперёд.

## Стек

- **Backend и обработка данных:** .NET (C#)
- **База данных:** PostgreSQL
- **Frontend:** React
- **Инфраструктура:** Docker
- **Внешние источники:** API hh.ru
- **Разбор текста вакансий:** NLP или LLM (с обязательной проверяемостью и объяснимостью рекомендаций)
