# Передача прототипа интерфейса

Формат результата по уточнению исполнителя: адаптивные страницы вместо изображений макетов.

`frontend-review.zip` содержит папку `frontend` с исходниками React, готовой сборкой `dist`, инструкциями и браузерными проверками. В архив не включаются зависимости, результаты тестов и локальные пользовательские данные.

Архив и его распакованные копии хранятся локально и исключены из Git. Актуальные исходники сайта находятся в `../frontend`.

Для просмотра: распакуйте архив, в папке `frontend` выполните `npm ci`, затем `npm run preview` и откройте адрес из терминала. Для работы с исходниками используйте `npm run dev`.

## Выполнено

- Лендинг, публичная статистика, вход, регистрация, восстановление пароля, кабинет и настройки.
- Нулевое состояние без плана, частичное освоение навыков, выбор навыка с прогнозом и вакансиями-основаниями.
- Одинаковый контекст расчёта в строке навыка и его карточке; будущие шаги обозначены как прогноз.
- Мобильная вёрстка от 360 px, включая окно навыка и выбор региона.
- Выпадающий выбор нескольких регионов с поиском, удалённой работой первым пунктом и удаляемыми отметками.
- Пять навыков на направление в сводке лендинга.
- Email, форма смены пароля и подтверждение удаления учётной записи; действия демонстрационные в пределах локального профиля.
- Палитра с HEX-кодами в README фронтенда; контраст акцента на светло-зелёном фоне 5,35:1.
- Сборка и семь браузерных проверок прошли 06.10.2026.
