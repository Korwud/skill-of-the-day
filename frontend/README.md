# Интерфейс «Навык дня»

Адаптивный интерактивный прототип на React + Vite. Изображения макетов заменены страницами. Backend и API hh.ru пока не подключены.

## Запуск

```sh
cd skill-of-the-day/frontend
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно http://127.0.0.1:5173).

```sh
npm run build
npx playwright test
```

Проверки используют установленный Google Chrome. При его отсутствии измените `channel` в `playwright.config.js` и установите браузер Playwright.

## Страницы

- `#/` — лендинг.
- `#/market` — публичная статистика трёх направлений.
- `#/login`, `#/register`, `#/reset` — формы входа, регистрации и восстановления пароля; отправка демонстрационная, пароли не сохраняются.
- `#/plan` — личный кабинет. Переключатели показывают нулевой экран и частично освоенные навыки. Выбор навыка открывает окно с приростом и вакансиями-основаниями; отметка освоения пересчитывает план.
- `#/profile` — направление, выпадающий выбор регионов с поиском, навыки, email, форма смены пароля и подтверждение удаления учётной записи.

Настройки, email и навыки сохраняются в localStorage. Удаление учётной записи в прототипе очищает эти данные и открывает страницу входа; отмена подтверждения сохраняет профиль. Форма смены пароля проверяет заполнение и совпадение новых паролей; сами пароли не сохраняются и не отправляются. Меню на мобильных устройствах раскрывается кнопкой. Вёрстка поддерживает ширину от 360 px; отдельного приложения нет.

Шрифты — системный Arial и Georgia для акцентных заголовков. Нет внешних изображений и загрузки шрифтов. Статусы сопровождаются текстом, порядок — номерами шагов; предусмотрены стили печати.

## Демонстрационные данные и границы реализации

`src/data.js` содержит по 120 синтетических вакансий для каждого направления. Все показатели сводки, охвата и прироста вычисляются из этих данных. Ссылки на несуществующие вакансии не создаются: в окне оснований явно указано, что реальные ссылки появятся после интеграции. Цитаты также демонстрационные.

План выбирает набор отсутствующих навыков одной из ближайших вакансий с наибольшим приростом охвата, затем повторяет расчёт ещё два раза. Это демонстрационный алгоритм для проверки интерфейса, который требуется согласовать с аналитиком. Прирост навыка и вакансии-основания используют один контекст в строке шага и в открываемой из неё карточке: текущие знания плюс навыки предыдущих шагов. Для будущих шагов карточка явно подписана как прогноз. Освоение навыка пересчитывает значения; повторное добавление уже освоенного навыка даёт нулевой прирост.

Новый локальный профиль начинается без навыков. При пустом наборе отображается нулевой экран без плана; при частичном освоении — план. Минимальное количество освоенных базовых навыков для появления плана не задаётся. Демонстрационные переключатели позволяют сразу просмотреть оба состояния.

Базовые навыки заданы отдельным справочником `basicSkills` и не зависят от позиции в общем списке или частоты вакансий. Предлагаемый состав для согласования с аналитиком:

| Направление | Базовые навыки |
| --- | --- |
| Системный анализ | Работа с требованиями, моделирование данных, SQL, REST API, UML |
| Разработка C# | C#, .NET, SQL, Git, REST API |
| Тестирование ПО | Тест-дизайн, тест-кейсы, SQL, REST API, Postman |

Это предложение для прототипа, а не утверждённый заказчиком справочник.

Справочник регионов пока содержит три города и удалённую работу. Несколько выбранных пунктов соединяются условием «ИЛИ»; пустой выбор означает всю Россию. Полный справочник hh.ru, серверное хранение, реальная авторизация, ресурсы обучения и еженедельный сбор данных относятся к следующей интеграции.

История срезов не имитируется: кабинет показывает сообщение о накоплении данных.

## Передача результата

Архив `../delivery/frontend-review.zip` содержит исходники, собранный интерфейс и инструкции запуска. Для просмотра распакуйте архив, перейдите в `frontend`, выполните `npm ci`, затем `npm run preview` (готовая сборка уже включена) либо `npm run dev`. HTML сборки нужно открывать через сервер, а не двойным щелчком по файлу.

Загрузка в папку проекта на Google Диске пока не выполнена: интеграция Google Drive не подключена. Архив подготовлен для передачи, установка и подключение Google Drive позволят выгрузить его в указанную папку.
